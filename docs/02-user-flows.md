# User Flows — MotoBekas

## Alur Pembeli (Guest → Login)

### Browse Motor
1. Buka app → landing di **Beranda**
2. Scroll grid motor, filter kategori, search
3. Tap kartu motor → lihat **Detail Motor**

### Beli Motor (trigger login)
1. Di halaman detail, tap **Beli Sekarang**
2. Muncul bottom sheet **Login/Registrasi**
3. Login sukses → lanjut ke flow chat/pembelian

### Lihat Showroom
1. Tap **Showroom** di bottom nav atau link di detail motor
2. Lihat profil, rating, review, stok motor showroom
3. Tap **Chat** atau **Hubungi** untuk komunikasi

## Alur Showroom

### Dashboard
1. Buka tab **Dashboard**
2. Lihat kartu statistik (stok, terjual, diproses, pendapatan)
3. Kelola stok motor (edit/hapus)
4. Tambah motor baru via FAB
5. Lihat daftar transaksi
