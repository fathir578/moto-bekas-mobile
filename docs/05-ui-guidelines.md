# UI Guidelines — MotoBekas

## Design System
- **Framework**: Material 3 (Material Design 3)
- **Primary**: `#1565C0` (Blue 800)
- **Secondary**: `#42A5F5` (Blue 400)
- **Background**: `#F5F7FA`
- **Surface**: White
- **Text Primary**: `#1A1A2E`
- **Text Secondary**: `#555566`

## Typography
- Font: Roboto
- Weight: Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800

## Komponen
### Cards
- Border radius: 14px
- Shadow: subtle (black 6% opacity, blur 8)
- Background: white

### Buttons
- Elevated button: Primary color, white text, radius 10px
- Outlined button: Primary border, primary text

### Chips
- Selected: Primary background, white text, radius 20px
- Unselected: White background, grey text

### AppBar
- Primary gradient: `#1565C0` → `#1976D2` → `#42A5F5`
- White text, no elevation
- Center alignment: false

## Padding
- Page horizontal: 16px
- Card padding: 16-18px
- Section spacing: 12-20px
