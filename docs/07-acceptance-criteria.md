# Acceptance Criteria — MotoBekas

## Guest Browsing
- [x] User bisa lihat beranda tanpa login
- [x] User bisa filter kategori motor
- [x] User bisa search motor
- [x] User bisa lihat detail motor
- [ ] User bisa lihat profil showroom

## Auth
- [ ] User diminta login hanya saat klik Beli/Jual
- [ ] Login via email + password
- [ ] Register sebagai pembeli atau showroom
- [ ] JWT token disimpan local
- [ ] Auto-refresh token

## Favorit
- [ ] Guest bisa tap ikon favorit → trigger login
- [ ] User login bisa nambah/hapus favorit
- [ ] Favorit persist antar sesi

## Dashboard Showroom
- [ ] Statistik realtime
- [ ] CRUD stok motor
- [ ] Daftar transaksi
- [ ] Tampilan responsive

## Performance
- [ ] Loading state di setiap request
- [ ] Error state jika gagal fetch
- [ ] Pull-to-refresh
- [ ] Smooth scroll (SliverAppBar)
